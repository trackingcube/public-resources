# YourTrack Ecosystem Logos

Public brand assets for products in the YourTrack ecosystem.

## Products

| Folder | Product |
|--------|---------|
| `yourtrack/` | YourTrack platform |
| `rnda/` | RNDA |
| `trackingcube/` | TrackingCube |

Drop logo files into the matching product folder.

## File naming

Use kebab-case. Suggested variants (add only what you need):

- `logo-full.png` — horizontal lockup (icon + wordmark)
- `logo-icon.png` — mark / icon only
- `logo-wordmark.png` — text only
- `logo-light.png` / `logo-dark.png` — variants for light or dark backgrounds

Prefer PNG with transparent background. SVG is fine when available.

## Usage

These assets are for public documentation, marketing, and UI branding.
Do not include clinical or identifiable data in filenames or image metadata.
