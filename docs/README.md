# Docs Index

This folder contains all official public documentation for TrackingCube.

## Sections

- `system-overview/` — concepts and docs that apply across multiple tiers
- `tiers/` — tier-specific public docs for operational use

## Tier Convention

Tier-based documentation is organized from `tier-1` to `tier-6`.

Inside each tier folder:
- `README.md` — entry point and scope
- `guidelines/` — process and policy docs
- `assets/` — PDFs, templates, static artifacts

## Authoring Guidelines

- Use Markdown (`.md`) for human-readable docs
- Place downloadable files under `assets/` inside each section
- Prefer concise filenames with kebab-case for new files
- Include a short "Last updated" and owner/contact section in each major doc
