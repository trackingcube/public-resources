# TrackingCube Public Resources

Public-facing documentation and resources for the TrackingCube system.

This repository is structured to support:
- System-wide public documentation
- Tier-based documentation (`tier-1` to `tier-6`)
- Public assets (PDFs, diagrams, templates)

## Repository Structure

- `docs/` — primary documentation root
  - `system-overview/` — platform-level and cross-tier docs
    - `assets/yourtrack-eco/` — ecosystem product logos (YourTrack, RNDA, TrackingCube)
  - `tiers/` — tier-specific documentation for `tier-1` to `tier-6`
